Sylva Laptop Sync

Sylva Laptop Sync is a personal tool with a single user: its author. It moves the author's own encrypted files between the author's own computers, using the author's own Google Drive as the carrier.

The tool requests only the Google Drive drive.file scope. That scope lets it read and write only the files and folders it created itself. It cannot see any other file in the Drive.

Nothing is stored anywhere except the author's own devices and the author's own Google Drive. Nothing is shared with anyone, and there is no server, no analytics, and no third party.
